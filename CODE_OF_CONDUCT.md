# Community code of conduct

Treat contributors and users respectfully, regardless of identity, experience,
background, or opinion. Offer specific constructive feedback, assume good faith,
and respect people's privacy and boundaries.

Harassment, threats, hate speech, sexual harassment, doxxing, credential sharing,
spam, and deliberate disruption are not welcome. These rules apply to repository
issues, pull requests, discussions, and spaces representing this project.

Report concerns privately to Tony Nguyen at admin@ndtan.net. Maintainers may remove
content, issue warnings, restrict participation, or ban repeated/severe offenders.
Reports will be handled discreetly; do not retaliate against a reporter.

This is a project-specific code of conduct, not an adoption of an external template.
