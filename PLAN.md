# ProxySieve implementation contract

Created and maintained by **Tony Nguyen** (`@nguyenduytan`).

Read these documents together, in order, before each milestone:

1. [Full product and implementation plan](PROXYSIEVE_PLAN.md).
2. [Accepted engineering refinements](docs/plan-refinements.md).
3. [Milestone checklist and verification evidence](PROGRESS.md).

The original plan remains intact. This entry point avoids maintaining two divergent
copies of a 5,500-line specification. Refinements clarify unspecified behavior;
they do not remove planned v1 features. Material deviations require an ADR.

Implement one testable milestone at a time. Never advertise planned capabilities
as shipped, and never mark unexecuted CI, integration, or release checks as passed.
