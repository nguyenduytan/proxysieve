# Support

The current `v1.0.x` line receives best-effort community maintenance. There is no
commercial support commitment or response-time SLA.

- Bugs and actionable feature requests: repository Issues using the provided forms.
- Design scope and status: PLAN.md and PROGRESS.md.
- Security issues: follow SECURITY.md privately.
- Community questions and usage help: repository Discussions.

Include your commit/version, OS, command, and reproducible sanitized example.
Never paste real credentials, authentication headers, or private user traffic.

Maintainer: **Tony Nguyen** (@nguyenduytan).
