# ProxySieve v1.0.0-rc.1

This is the first release candidate for ProxySieve v1.0.0. It is intended for
controlled local evaluation before the stable release, not unattended public
gateway deployment.

## Highlights

- HTTP forward, HTTPS CONNECT and SOCKS5 CONNECT listeners with explicit policy
  routing through HTTP, HTTPS or SOCKS5 upstream proxies and ordered chains.
- Revisioned proxies, sources, pools, policies, sessions, health, budgets, cache,
  alerts, shadow policies and atomic runtime activation/rollback.
- Embedded authenticated Admin Panel with a browser-only first-use workflow,
  responsive mobile layout, live traffic/events and sanitized audit history.
- Runtime-dependency-free Playwright and Puppeteer adapters with controlled Chrome
  E2E proof that configured blocked resources never reach the upstream fixture.
- Optional, default-off HTTPS Inspect for explicitly scoped HTTP/1.1 CONNECT hosts.
- WAL-consistent backup/restore, portable secret-free config export/import, doctor,
  DB maintenance, Extension API v1 and local examples.

## Security defaults

Admin and gateway listeners bind to loopback by default. There is no implicit
DIRECT fallback, no default password and no automatic extension download. Private
destinations are denied for untrusted traffic. A remote-resolving proxy requires
explicit operator trust when private-destination protection is active. HTTPS
Inspect is off until a local CA and explicit host scopes are configured.

## First route

Start with `config.example.yaml`, complete the one-time Admin setup, import and test
one proxy, review/approve its remote-DNS trust only when justified, add it to a
pool, generate the passthrough policy, activate the complete inventory and send one
controlled request. Confirm its matched policy, pool, proxy and byte attribution in
Traffic. See the [README](../../README.md) and [documentation index](../README.md).

## Compatibility and known limits

Artifacts target Linux, Windows and macOS on amd64/arm64; the tag workflow executes
the amd64 archive on each OS and build-verifies arm64. SOCKS5 UDP, HTTP/2/3
inspection, QUIC inspection, remote Admin TLS, persistent encrypted secret storage,
published container images, framing-level billing and cost-denominated budgets are
not part of this RC. See [release compatibility](../release.md) for exact contracts.

## Verification

lint/tests/build, dependency scans, six fuzz targets, the native protocol matrix,

SPDX SBOM, portable provenance, supported GitHub attestations and native archive
smoke. Report security issues privately according to
[SECURITY.md](../../SECURITY.md).
