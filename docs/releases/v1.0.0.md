# ProxySieve v1.0.0

ProxySieve v1.0.0 is the first stable release. It promotes the accepted
`v1.0.0-rc.1` runtime and compatibility contracts after the final hosted release
gates passed without a known P0/P1 correctness or security defect.

## Highlights

- HTTP forward, HTTPS CONNECT and SOCKS5 CONNECT listeners with deterministic
  policy routing through HTTP, HTTPS or SOCKS5 upstream proxies and ordered chains.
- Revisioned proxies, sources, pools, policies, sessions, health, budgets, cache,
  alerts and atomic runtime activation or rollback.
- Embedded authenticated Admin Panel with first-run setup, responsive operation,
  live traffic/events and sanitized audit history.
- Optional scoped HTTPS Inspect, browser adapters, safe backup/restore, portable
  config import/export and Extension API v1.
- Native Linux, macOS and Windows archives for amd64 and arm64 with checksums,
  SPDX JSON SBOM and portable provenance.

## Upgrade from the release candidate

No configuration schema, database migration or public protocol changed between
`v1.0.0-rc.1` and `v1.0.0`. Stop ProxySieve, keep a current backup, replace the
binary and run `proxysieve doctor --file config.yaml` before restarting.

## Security defaults and limits

Gateway and Admin listeners bind to loopback by default. DIRECT has no implicit
fallback, private destinations are denied for untrusted traffic and HTTPS Inspect
remains off until explicitly scoped. SOCKS5 UDP, HTTP/2/3 or QUIC inspection,
remote Admin TLS, encrypted persistent secret storage and published container
images are outside v1.0.0. See the [README](../../README.md),
[security policy](../../SECURITY.md) and [release guide](../release.md).

## Verification

The stable commit is gated by backend tests/race/lint/build/container smoke,
frontend lint/tests/build, dependency scans, fuzz smoke, native protocol matrices,
controlled Chrome E2E, hot-path benchmarks, bounded load smoke and native archive
execution. Release assets are verified before publication.
